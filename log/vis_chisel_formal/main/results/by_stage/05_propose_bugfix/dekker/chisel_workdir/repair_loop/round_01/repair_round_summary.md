Fix SA4_turn_one_hot assertion_error: replaced `assertOneHot(turn, ...)` on 1-bit turn register with `fvAssert(turn === 0.U || turn === 1.U, "SA4_turn_one_hot")`. Root cause: assertOneHot on a 1-bit signal checks `turn === 1` (exactly one bit set), but turn is legitimately 0 (RegInit(0.U(1.W))). The fix preserves the assertion label and checks the intended property that turn is always 0 or 1, which holds trivially for a 1-bit UInt. No homologous assertions found (assertOneHot used only once).

Fix assertion_error in LA1_liveness_L2_to_CS and LA3_liveness_trying_to_CS: replaced astRelaxedLiveness (which counts all clock cycles unconditionally) with custom pending/timer logic that only increments the timer during productive cycles where self === tracked_self && !io.pause. Root cause: io_select and io_pause are unconstrained external inputs; io_pause can stall the tracked thread at L5 indefinitely, and io_select can switch self away from the tracked thread, preventing progress. astRelaxedLiveness counts every clock cycle regardless, so the timer expires while the tracked thread is blocked. The custom counter only counts cycles where the tracked thread is actually the active thread and the FSM is not paused, so the bound accurately reflects execution progress rather than wall-clock time.

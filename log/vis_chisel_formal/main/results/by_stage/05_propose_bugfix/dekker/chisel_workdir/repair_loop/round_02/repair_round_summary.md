Fix assertion_error in LA1_liveness_L2_to_CS, LA2_liveness_L5_to_CS, LA3_liveness_trying_to_CS: all three liveness assertions used `pc(self)` in both request and response, but `self` (driven by nondeterministic `io_select`) can change between request and response cycles, causing the response to check the wrong process. Fix adds per-assertion snapshot registers (`tracked_self_l2`, `tracked_self_l5`, `tracked_self_try`) that latch `self` when each request fires, and uses the snapshot for response evaluation. Root cause: self is a register that follows io.select with one-cycle delay; io.select can change arbitrarily, making `pc(self)` non-deterministic across assertion monitoring windows. All three structurally identical assertions repaired homolougously with the same pattern.

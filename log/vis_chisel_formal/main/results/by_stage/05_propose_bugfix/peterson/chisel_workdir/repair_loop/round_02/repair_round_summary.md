Round 2/3: Fix DUT architectural bug — replace single-threaded `switch(pc(selfIdx))` with a for-loop processing both processes independently each cycle. Root cause: original design serialized execution through `io_select`/`self` register, so when self=process1, process0 was completely stalled regardless of its entry condition being met. This broke all 6 remaining properties. Fix restores correct Peterson semantics where each process independently evaluates its L3 condition each cycle. Also fixed Scala `(~i).U` issue (bitwise NOT on Scala Int produces negative values) — replaced with `(if (i==0) 1 else 0).U`. All assertion labels preserved unchanged.

Round 3/3. DUT bug fix for 6 remaining liveness failures (slot{0,1,2}_forward_progress and slot{0,1,2}_ready_eventually_issues). Root cause: issue-priority age conditions `(qAge(I) | ~opsReady(J))` in all 6 issue signals (issue0_0, issue0_1, issue0_2, issue1_0, issue1_1, issue1_2) did not account for invalid younger slots. When slot J was invalid but opsReady(J)=1 (valid input from testbench), the condition `~opsReady(J)=0` blocked the current slot from issuing even though no instruction existed in slot J to compete. Fix: added `| ~valid(J)` to each age-condition clause across all 6 issue signals (12 clauses total). This allows an older slot to issue past an invalid younger slot regardless of that slot's opsReady value. The `valid(J)` gate directly checks slot occupancy, preventing the false arbitration stall demonstrated in the t=70ns waveform where valid(2)=0 but opsReady(2)=1 blocked issue0_0. All assertion labels preserved unchanged.

Round 1/3: Fixed DUT bug in SlaveND counter logic (reqAckRed.scala line 71). Changed `count := count + nd` to `count := 1.U` in the `elsewhen(count === 0.U)` branch. Root cause: when nd=lfsr(0)=0 and count=0, the counter stalled indefinitely, violating bounded liveness for both `working_eventually_ready` (ReqAck) and `start_eventually_ready` (SlaveND). The fix guarantees count always progresses from 0 regardless of LFSR state, preserving the original design intent that ready asserts within 3 cycles after start. All assertion labels preserved unchanged.

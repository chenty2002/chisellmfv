Repair round 1: Fixed DUT bug in usb_phy.scala (lines 73-87). Root cause: register update race condition between rst_cnt and usb_rst_reg — when io.rst deasserts in the same cycle rst_cnt reaches 31, rst_cnt resets to 0 (via when(!io.rst)) while usb_rst_reg captures the old rst_cnt=31, causing inconsistent state. Fix: introduced next_rst_cnt wire that computes the next counter value first, then both rst_cnt and usb_rst_reg use the same next_rst_cnt value for their assignments. This ensures rst_cnt and usb_rst_reg stay consistent when io.rst deasserts, fixing both failing assertions (usb_rst_implies_cnt_31, rst_cnt_stable_during_usb_rst). All assertions preserved with original labels.

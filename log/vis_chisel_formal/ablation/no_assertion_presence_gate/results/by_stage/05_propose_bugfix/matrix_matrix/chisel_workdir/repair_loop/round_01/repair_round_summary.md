Fixed `write_sets_shadow_valid` assertion (lines 112-117). Root cause: timing mismatch — the `assertImplies(!io.r_w && io.row =/= io.col, shadowValid(posn), ...)` checked the shadowValid register in the same cycle it was being written to. Since `shadowValid` is a `RegInit` with non-blocking semantics, the updated value only becomes visible at the next clock cycle, causing a spurious CEX. Replaced with a 1-cycle delayed check using `RegNext(!io.r_w && io.row =/= io.col)` (wasWrittenNonDiag) and `RegNext(posn)` (prevPosn) to sample the write condition and position from the previous cycle, then verify `shadowValid(prevPosn)` is true one cycle later. The assertion label `write_sets_shadow_valid` is preserved. No structurally identical assertions found in the source (inspection shows no other assertion with the same `assertImplies` pattern checking register update timing).

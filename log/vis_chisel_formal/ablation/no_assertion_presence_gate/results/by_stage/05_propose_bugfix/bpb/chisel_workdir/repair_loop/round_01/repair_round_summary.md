Round 1/3: Fix saturating-counter overflow/underflow assertions (target: bank0_no_overflow_on_taken, plus 7 homologous assertions). Root cause: shared `update_addr` register captured io.buffer_addr on EVERY io.update, so a bank0 update at cycle N (antecedent true) would be overwritten by a bank1 update at cycle N+1 before the 1-cycle-delay consequent reads `update_addr`. Fix: replace single `update_addr` with four per-bank registers (`update_addr_bank0..3`), each updated only when io.buffer_offset matches that bank. Removed unused `update_active`. All 8 overflow/underflow assertion consequents updated to reference the correct per-bank register. Labels preserved unchanged.

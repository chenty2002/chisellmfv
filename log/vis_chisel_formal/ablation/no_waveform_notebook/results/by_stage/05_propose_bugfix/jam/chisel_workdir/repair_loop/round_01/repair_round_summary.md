Round 1/3: Fix uninitialized RegNext registers causing false counterexamples in formal verification. Root cause: formal reset signal is never asserted, so RegNext registers (old_slots, old_valid, old_move, old_empty) get arbitrary initial values from the formal solver. This caused old_valid to be arbitrarily 1, triggering assertions to fire when no valid move occurred. Fix: added explicit initialization values — old_valid initialized to false.B (no valid move at reset), old_move to 0.U, old_empty to 0.U, and old_slots to the initial board configuration [RIGHT,RIGHT,RIGHT,EMPTY,LEFT,LEFT,LEFT]. This ensures deterministic initial register values regardless of reset behavior, fixing move_fills_empty_slot and move_empties_source assertions. The homologous assertions (move_fills_empty_slot and move_empties_source) both share the old_valid register; both are repaired by the same initialization.

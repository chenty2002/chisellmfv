Fixed clearBit bug (good_bakery.scala lines 55-57): bitmask literals "b001".U, "b010".U, "b100".U lacked explicit width, so Chisel created 1-bit, 2-bit, 3-bit masks respectively. ~1'b1 = 1'b0 extended to 3'b000 (clears all bits); ~2'b10 = 2'b01 extended to 3'b001 (clears bits 1+2). Added explicit width (in.getWidth.W) to each literal so masks are properly sized: ~3'b001=3'b110, ~3'b010=3'b101, ~3'b100=3'b011, each clearing only the intended bit. This corruption of defer registers during L10 exit broke the ordering priority, causing two processes to enter CS simultaneously (violating MutualExclusion) and also causing spurious DetTransition failures. All 19 failing properties (MutualExclusion + all DetTransition) share this single root cause.

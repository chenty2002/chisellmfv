Round 3: Fixed DUT bug in sAnalisReq — unconditional fu assignments (fu1:=ru1..fu4:=ru4) at lines 85-88 caused fu bits to be set for ALL requests even when only the highest-priority one was enqueued by the priority encoder. This created a livelock: e.g., fu4 was set when U3 was enqueued; fu4 had no queue entry and could never be served. Fix: moved each fu assignment inside the corresponding priority-encoder conditional branch (fu1:=true.B inside ru1&&!fu1 when-branch, etc.), and removed the unconditional fu1:=ru1..fu4:=ru4 block. This ensures only the actually-enqueued request gets its fu bit set, preventing stuck-fu scenarios. Also addresses the shared root cause of `request_eventually_granted` failures (stale fu → no enqueue → no grant). Assertion labels preserved unchanged.

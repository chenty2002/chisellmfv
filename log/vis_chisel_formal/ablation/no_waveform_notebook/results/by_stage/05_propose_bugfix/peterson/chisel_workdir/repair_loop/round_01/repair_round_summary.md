Repair round 1/3: Fixed liveness_process0 assertion failure. ERROR_TYPE=dut_bug. Root cause: original design used a single switch statement operating on only one process per cycle (pc(selfIdx) where self:=io.select). When select switches, the previous process is abandoned mid-execution, causing both processes to starve at L3. Fix: replaced the single-process switch with a for-loop that runs both processes' state machines independently every cycle, modeling true concurrent execution of Peterson's algorithm. Each process i uses myIdx=i.U and otherIdx=~myIdx for its state transitions and turn/condition logic. The last-writer-wins semantics on the shared turn register when both processes transition through L2 simultaneously correctly models the non-deterministic arbitration that Peterson's algorithm requires. Assertion labels liveness_process0 and liveness_process1 are preserved unchanged.

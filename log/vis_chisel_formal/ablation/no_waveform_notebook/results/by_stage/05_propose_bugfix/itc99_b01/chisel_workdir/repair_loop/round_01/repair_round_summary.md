Round 1 fix: Changed io.OUTP and io.OVERFLW from registered outputs (outpReg, overflwReg) to combinational outputs derived directly from current state and inputs. The root cause was that registered outputs appeared one cycle after the state that set them, causing a mismatch with the combinational state decode used in assertions. Specifically: io.OVERFLW := is_e (combinational); io.OUTP := Mux(in_xor_group, io.LINE1^io.LINE2, ~(io.LINE1^io.LINE2)). Removed outpReg and overflwReg registers along with their assignments inside the switch. This fixes all three failing assertions (OVERFLW_only_in_state_e, OUTP_XOR_in_states_a_b_c_e_wf0, OUTP_XNOR_in_states_f_g_wf1) in a single, minimal change. All assertion labels preserved exactly.
